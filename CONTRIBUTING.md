# Contribuir

Contribuições devem tornar o harness mais claro, útil ou seguro para mais projetos.

- Descreva o problema real que a mudança resolve.
- Prefira instruções portáveis e ferramentas que o projeto já usa.
- Mantenha pequeno o fluxo para tarefas pequenas; não transforme recomendações em etapas obrigatórias universais.
- Não inclua segredos, dados pessoais ou conteúdo de projetos privados.
- Para mudança de instruções, verifique links, nomes de arquivos e consistência entre `AGENTS.md` e `SKILL.md`.
- Exemplos devem ser fictícios ou estar liberados para publicação.

Ao abrir uma solicitação de mudança, informe o comportamento anterior, o esperado e como você verificou a proposta.
